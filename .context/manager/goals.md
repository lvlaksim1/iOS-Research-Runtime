# Manager goals

1. Advance from the verified Windows recovery/root-shell foundation to a verified full-iOS boot boundary, beginning with IOS-M2 evidence that identifies the first concrete blocker after recovery root shell.
2. Reduce technical uncertainty through evidence-driven engineering rather than speculative diagnostic churn.
3. Preserve one persistent accountable Project Manager across runtime replacement, with project state and durable memory owned by this repository.
4. Keep strategic project control with the Project Manager while using PP-RM A/B as a continuous bounded execution mechanism when autonomous continuation is useful.
5. Preserve exact product/CI provenance so claims about boot progress, regressions, or milestone completion can be independently checked.
6. Make PP-RM operation routine and recoverable: Manager issues bounded work packages and high-level checkpoints; A/B execute, verify, hand off, and stop for Manager when strategic re-planning is required.
7. Progress in staged milestones toward system userland, core services, graphics/input, SpringBoard, interactive iOS, Apple-service feasibility, Windows productization, and reliability without collapsing those stages into one unverifiable objective.
