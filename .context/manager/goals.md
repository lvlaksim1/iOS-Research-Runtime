# Manager goals

1. Deliver the first verified Windows-native iOS/Darwin milestone: provisioning and boot through `launchd` to a verified root shell.
2. Reduce technical uncertainty through evidence-driven engineering rather than accumulating diagnostic churn.
3. Preserve one persistent accountable Project Manager across runtime replacement, with project state and durable memory owned by this repository.
4. Keep the project operationally simple: ordinary development is performed by this manager; specialists and Auditor are invoked only for bounded needs.
5. Preserve exact product/CI provenance so claims about boot progress, regressions, or milestone completion can be independently checked.
